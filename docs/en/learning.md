## Expanding the foundation

These are active areas of study, not claims of mastery:

- **React** — component-based interface development
- **TypeScript** — clearer contracts and safer JavaScript
- **SQL and data modeling** — stronger queries, constraints and schema decisions
- **Automated testing** — reliable changes and regression prevention
- **Software architecture** — boundaries, responsibilities and trade-offs
- **Application security** — authentication, authorization, validation and safer defaults
- **Networking and infrastructure** — understanding how applications are accessed and operated
- **Cloud and DevOps fundamentals** — the path from code to a repeatable deployment

## Learning method

I try to connect each subject to a concrete problem:

```text
Why does it exist?
When should I use it?
What trade-offs does it introduce?
How can I verify that it works?
How does it affect the rest of the system?
```

This keeps learning grounded. The goal is not to collect a longer technology list, but to make better decisions and build more reliable software.
