# Estudos atuais

Estou fortalecendo a stack que já utilizo enquanto amplio, gradualmente, meus conhecimentos em tecnologias e práticas que respondem às lacunas encontradas em projetos reais.

## Aprofundando a base

Estas são as tecnologias em que tenho mais experiência prática atualmente:

- **JavaScript** para lógica no navegador e no servidor
- **Node.js e Express** para aplicações backend e APIs REST
- **SQLite e fundamentos de SQL** para persistência, consultas e modelagem de dados
- **HTML e CSS** para interfaces de aplicações
- **Git e GitHub** para controle de versão e histórico dos projetos
- **PWA, funcionamento offline e sincronização** por meio do Hiperion Protocolos

## Expandindo conhecimentos

Estas são áreas de estudo ativas, não alegações de domínio:

- **React** — desenvolvimento de interfaces baseadas em componentes
- **TypeScript** — contratos mais claros e JavaScript mais seguro
- **SQL e modelagem de dados** — consultas, restrições e decisões de esquema melhores
- **Testes automatizados** — mudanças mais confiáveis e prevenção de regressões
- **Arquitetura de software** — limites, responsabilidades e trade-offs
- **Segurança de aplicações** — autenticação, autorização, validação e padrões mais seguros
- **Redes e infraestrutura** — entender como aplicações são acessadas e operadas
- **Fundamentos de Cloud e DevOps** — o caminho entre o código e uma implantação repetível

## Método de aprendizado

Procuro conectar cada assunto a um problema concreto:

```text
Por que isso existe?
Quando devo usar?
Quais trade-offs isso introduz?
Como posso verificar se funciona?
Como isso afeta o restante do sistema?
```

Isso mantém o aprendizado conectado à prática. O objetivo não é acumular uma lista maior de tecnologias, mas tomar decisões melhores e construir software mais confiável.

4. Aprofundar fundamentos de segurança, implantação e observabilidade.
