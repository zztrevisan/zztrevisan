## NFSe Hiperion

A project focused on **business process automation**.

The goal is to reduce repetitive work involving invoice downloads and document organization across multiple companies.

```text
MANUAL PROCESS

Access system
     │
Select company
     │
Select period
     │
Download files
     │
Organize documents
     │
Repeat
```

Becomes:

```text
ONE ACTION
    │
    ▼
AUTOMATION
    │
    ├── Company A
    ├── Company B
    ├── Company C
    │
    ▼
ORGANIZED DOCUMENTS
```

The core idea is simple:

> **Turn repetitive operational work into a predictable automated process.**
